# sumy-ground-dashboard
Звіт за результатами аналізів ґрунтів територій, що постраждали від бойових дій.  Проєкт «Громадська оцінка ризиків для земель і вод з метою безпечного відновлення громад Слобожанщини», ГО «НОВА ЕНЕРГІЯ» у межах Проєкту «Імпульс», реалізується Міжнародним фондом «Відродження» та Фондом Східна Європа за фінансування Норвегії (Norad) та Швеції (Sida)
